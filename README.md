# 🤖 Autonomous Multi-Agent AI System | CrewAI + LangGraph + Gemini 2.0

> A fully autonomous 2-agent AI workflow that scrapes B2B leads and writes hyper-personalized cold emails without any human intervention.

### 🎥 YouTube Demo Video:
**Watch Full Build Tutorial Here:** https://youtu.be/Z0-qBjYDdzU

In this video, I built a complete multi-agent system using CrewAI for agents and LangGraph for orchestration. Perfect for AI Automation Agency owners!

### 🚀 What This Project Does:

**Agent 1 - Lead Researcher (Scraper):**
- Uses a custom tool to find high-quality B2B leads for AI Automation niche
- Extracts Company Name, Contact Person, Email, and Business Pain Point
- Currently configured for Pakistan market

**Agent 2 - Email Copywriter:**
- Takes scraped leads and writes personalized outreach emails using Gemini 2.0 Flash
- Addresses each lead by name and their specific business problem
- Ready-to-send high-converting copy

**Orchestration:**
- **CrewAI:** For role-based agent collaboration (Researcher -> Writer)
- **LangGraph:** For stateful workflow control with START -> execute_crew -> END

### 🛠️ Tech Stack:
- **Framework:** CrewAI, LangGraph, LangChain
- **LLM:** Google Gemini 2.0 Flash
- **Language:** Python 3.10+
- **Tools:** Custom Python Tool, python-dotenv

### ⚙️ How to Run Locally:
1. Clone: git clone https://github.com/usmanAISystem/autonomous-multi-agent-system-crewai-langgraph.git
2. Install: `pip install -r requirements.txt`
3. Add `.env` file: `GEMINI_API_KEY=your_key_here`
4. Run: `python multiple.py`
